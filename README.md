# Typing Speed Tester

A React-based typing speed test that measures your WPM, CPM, and accuracy against a 60-second timer.

🔗 **Live Demo:** https://renuka-typing-tester.netlify.app/

## Features
- Random paragraph each round
- Live WPM, CPM, mistake counter
- Visual feedback for correct/wrong characters
- 60-second timed challenge
- Reset and try again

## Tech Stack
- React
- Vite
- CSS

## Run Locally
```bash
npm install
npm run dev
